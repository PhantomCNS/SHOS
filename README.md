# SHOS
Smart Home Operating System

## The main purpose:
A smart home system that observes the environment and controls devices

## Required functions:
-Measuring Humidity & Temperature
-Gas detection
-Door automation
-Distance detection
-Displaying results
-Controlling via phones
-Alert system
-Emergency system
-Controlling windows

## Used materials:
-ESP32
-MQ-2
-Servo
-Relay
-LCD 16*2
-Buzzer
-LEDs
-BreadBoard

## Communication methods:
-UART
-I2C
-Wi-Fi
## Used Language(s):
- MicroPython
